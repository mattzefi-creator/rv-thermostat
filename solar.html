This browser can't hear the controllers

The solar page reads the live data your Victron controllers broadcast over Bluetooth. That needs a browser feature that isn't on by default.

  1. Android: open Chrome, type chrome://flags in the address bar, search for Experimental Web Platform features, set it to Enabled, and restart Chrome.
  2. iPhone: Bluefy may not support this. If it doesn't, an Android phone or tablet with Chrome is the way to go.

Add a solar controller

Each SmartSolar controller is added once. You'll need its encryption key from the VictronConnect app.

Picked . Now paste its encryption key:

  1. Open VictronConnect and tap the controller.
  2. Tap the gear icon, then the three-dot menu, then Product info.
  3. Make sure Instant readout via Bluetooth is on, then tap Show next to Instant readout details.
  4. Copy the Encryption key (32 letters and numbers) and paste it below.

The key stays on this phone. Nothing connects to the controllers, so VictronConnect keeps working at the same time.
